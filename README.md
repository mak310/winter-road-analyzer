# Winter Road Analyzer

## 概要

Winter Road Analyzer は、スタッドレスタイヤ開発で得た知見を活かし、冬季路面の状態を評価するアプリケーションです。

路面状態に応じて推定摩擦係数（μ）、危険度、推奨タイヤ、推奨速度を表示し、安全運転支援につながる情報を提供します。

将来的には画像認識AIを導入し、路面画像から自動判定を行うことを目標としています。

---

## 開発背景

スタッドレスタイヤの開発では、路面状態と摩擦係数（μ）の関係が重要です。

本アプリでは以下の考え方を取り入れています。

- 路面状態の分類
- 推定摩擦係数（μ）の評価
- 危険度評価
- 推奨タイヤ表示
- 推奨速度表示

将来的にはAIによる路面認識と組み合わせ、自動運転や運転支援システムへの応用を目指しています。
